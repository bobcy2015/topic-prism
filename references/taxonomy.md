# 话题棱镜 · 分类维度

先汇总，后分类。60 条（或实际可用条数）全部落表之后，再统一按下面七个正交维度打标，**不要一边搜一边分类**——那会导致前 20 条的分类标准和后 40 条对不上。

## 维度一：主题域（每条只填一个主域）

用于给报告分章节。允许自定义子域，但主域必须从下列取值里挑一个：

- 科技 / 产品
- 商业 / 财经
- 社会 / 公共事务
- 文化 / 娱乐
- 生活 / 消费
- 健康 / 医疗
- 教育 / 职场
- 政策 / 法规
- 其他

判不清时选「其他」并在备注写明争议点，不要硬塞。

## 维度二：内容性质（每条只填一个）

- **事实**：可核验的事件、数据、公告
- **观点**：评论、分析、预测
- **争议**：存在明确对立立场
- **数据**：榜单、统计、调研结果
- **教程**：方法论、操作步骤、经验帖
- **一手材料**：原始文档、公告、论文、源码

这一维决定读者该用什么态度读：事实可以直接采信，观点必须看作者立场，一手材料优先级最高。

## 维度三：信息确定性（每条只填一个）

- **已证实**：至少一个权威一手源，或多源交叉一致
- **待证实**：单一信源，尚未交叉验证
- **存疑**：存在与主流说法相反的证据
- **无法判定**：信源不可追溯

**这一维必须在报告里显式呈现**，它是整份汇总可信度的地基。

## 维度四：影响面（每条只填一个）

- **个人**：只影响具体个体的选择
- **行业**：影响某个垂直领域的从业者
- **公共**：影响不特定多数人

## 维度五：立场倾向（每条只填一个）

决定「舆论到底偏哪边」，是用户最容易直接问出口的那一维。

- **正面**：认可、支持、看好
- **中性**：纯信息转述、不带评价（通稿、参数稿多属此类）
- **负面**：明确否定、不看好、批评
- **质疑**：对具体事实提出疑问或指出漏洞（数额口径、续费机制、生态承诺），不等于否定

判读顺序：先看作者在哪一段下了判断句，再看结论句。**新闻转述不要硬判成正负面**，那是中性。
一条内容同时有肯定和质疑时，看它的**结论落在哪边**，落在质疑侧就记「质疑」。

分布检查：若某一类超过 70%，复查是不是把中性稿都判成了正面。

## 维度六：信源权威度（每条只填一个）

回答「谁在说」。它与「信息确定性（说的是不是真的）」是两条独立的轴：官媒也可能转述出错，匿名论坛偶尔是唯一一手信源，两个维度都要填，不要互相替代。

| 取值 | 判定 | 典型来源 |
|---|---|---|
| 官媒 / 机构发布 | 党央媒、政府机关、监管机构、上市公司公告、官方账号的一手发布 | 新华社、人民网、工信部、交易所公告 |
| 权威媒体 / 专业机构 | 有采编资质或研究能力的媒体与研究机构 | 财新、财联社、36氪、高校与研究院所 |
| 认证账号 | 平台认证的机构号、企业号、百万粉以上专业账号 | 蓝V、品牌官号、认证专家 |
| 自媒体 / 个人博主 | 无机构背书但具名的创作者、KOL、垂类博主 | 个人公众号、B站UP主、知乎答主 |
| UGC / 匿名讨论 | 用户生成内容、匿名或无法追溯的发言 | 贴吧、匿名论坛、评论区、无署名爆料 |
| 无法判定 | 来源为空、被全站转载且找不到原始出处 | 聚合站、无署名搬运 |

判定顺序：**先看原始发布者，再看转载者**。转载站的权威度归转载站，但要在备注注明原发；找不到原始出处的，填「无法判定」，不要因为转载站很大就往上抬。

同一事件合并了多个来源时，按**主条目（热度最高那条）定档**；若合并来源里有明显更高的一档（如自媒体转述官媒通稿），只在备注写明「转自官媒」，档位不因此升级——避免一条转述把整簇拉高。

## 维度七：时效形态（每条只填一个，可留空）

- **突发**：刚发生、还在演化
- **持续**：已发酵一段时间、有前情
- **长尾**：周期性反复出现的常青话题

## 附加字段：平台分布

不参与分类，但每条都要记录该事件出现在哪些平台（去重合并后的结果）。跨平台数量是热度加分项的来源，也是判断「这是不是全网共识」的依据。

## 打标质量红线

- 七个维度中，前六个必须全部有值（时效形态可留空）；缺「信源权威度」等同没做来源核验
- 以上强制要求只针对**正文** N 条；附录（热度未知）条目可不打标
- 「信息确定性」不允许因为赶时间而全部填「待证实」——那就是没做核验
- 分类完成后统计一次分布，如果某一维度出现 >80% 集中在单一取值，回头复查打标是否在偷懒
