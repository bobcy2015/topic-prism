# 报告模板（渲染时按此结构输出）

由 `python3 scripts/prism.py report` 自动生成，此文件用于人工校对结构是否到位。

---

# 话题棱镜 · {话题名}

> 生成时间：{YYYY-MM-DD HH:mm} ｜ 检索窗口：{起} ~ {止} ｜ 地域范围：{国内/全球}

## 一、检索与筛选口径

- 候选池：{N} 条（原始检索结果）
- 热度放行：{N} 条
- 事件去重后：{N} 个唯一事件
- 最终纳入：{N} 条（目标 {M} 条）
- 判定模式：{absolute / relative} —— {一句说明}
- 缺口说明：{无 / 实际可用信息量仅 X 条，未做填充凑数}

## 二、分类矩阵

**主题域**：{域 A} {n} 条 / {域 B} {n} 条 / ...
**内容性质**：事实 {n} / 观点 {n} / 争议 {n} / ...
**信息确定性**：已证实 {n} / 待证实 {n} / 存疑 {n}
**影响面**：个人 {n} / 行业 {n} / 公共 {n}
**时效形态**：突发 {n} / 持续 {n} / 长尾 {n}

> 打标自查：{某维度取值过于集中则在此提示}

## 三、时间线（按日期倒序，越新越靠前）

### {YYYY-MM-DD}（{n} 条）

- {「新」}{E001 标题} ｜ {平台} ｜ 热度 {xx.x} ｜ {立场倾向}

（日期按倒序排列，无日期的条目归入「日期未知」组）

## 四、条目明细（组内按热度降序）

### {主题域 A}（{n} 条）

**E001 {标题}**
- 热度分 {xx.x} ｜ 平台：{微博、知乎} ｜ 作者：{xxx} ｜ 合并 {n} 条重复
- 分类：主题域={} ；内容性质={} ；信息确定性={} ；影响面={} ；立场倾向={} ；信源权威度={} ；时效形态={}
- 摘要：{一两句}
- 源：{URL}

（其余条目同结构）

## 五、与上次对比（给了 --baseline 才有）

- 基线：{上次生成时间}（共 {N} 条）
- 本次：新增 {a} 条 / 消失 {r} 条 / 延续 {k} 条

**新增**：{E00x 标题 ｜ 日期 ｜ 热度}
**消失**：{标题 ｜ 上次热度}

## 六、方法学与限制

- 热度门槛：绝对地板 100；大流量平台 1000、中等平台 300、垂直/小众源 100。
- 低热度选题（达标占比 <50%）自动切换为题域相对线：渠道门槛下调至绝对地板，按热度分排序取前 N。
- 排序是「热度分」而非真实全网浏览量排名：各平台指标口径不同（阅读量/播放量/热度值/榜单名次），
  跨平台仅做归一化近似，不可当绝对值横向对比。
- 同作者跨平台同发、或标题/正文高度重合的内容已合并为一个事件，合并后跨平台数量计入热度加分。
- 「信息确定性」维度未达已证实的事件，采纳前需自行复核。

## 七、值得优先关注的几条（可选）

从结果里挑 3～5 条，说明为什么值得先看（一手材料、跨平台共识、与用户目标最相关）。这一节给判断，
但不给投资、医疗、法律类结论性建议。

## 附、热度未知条目（配额内，无公开量化指标，不参与排名）

> 以下条目平台未公开指标，价值在内容本身；采纳前请自行判断信源。

- **{E 编号} {标题}** ｜ {平台} ｜ 热度未知

（条目不足配额上限时说明实际纳入数；超出的列在「未纳入条目与原因」）

## 质检清单（渲染前逐条过）

- [ ] 条目数与口径章节数字一致
- [ ] 每条都有 URL
- [ ] 正文七个维度里前六个全部有值（时效形态可空；立场倾向、信源权威度必填）；附录条目可不打标
- [ ] 附录条数没超过配额，超出的列进了「未纳入条目与原因」
- [ ] 没有把热度分描述成浏览量
- [ ] 缺口如实写明，没有硬凑
- [ ] 限制章节完整
