## 九、方法学与限制

- 热度门槛：绝对地板 100；大流量平台 1000、中等平台 300、垂直/小众源 100。
- 低热度选题（达标占比 <50%）自动切换为题域相对线：渠道门槛下调至绝对地板，按热度分排序取前 N。
- 总分是五项加权：热度、跨平台分布、互动量、时间新鲜度、**来源质量**。来源质量占第二权重，
  因为营销号的 10 万+ 很容易压过权威媒体的 2 万；命中标题党 / AI 水文 / 营销号硬旗标的内容不进正文。
- 排序是「热度分」而非真实全网浏览量排名：各平台指标口径不同，跨平台仅做归一化近似。
- 同作者跨平台同发、或标题/正文高度重合的内容已合并为一个事件，合并后跨平台数量计入热度加分。
- 「信息确定性」维度未达已证实的事件，采纳前需自行复核。
- 来源质量分由执行方按站点 / 账号 / 页面三级证据判断，属人工判断，不是平台给出的客观分。

## 十、值得优先关注的几条

从结果里挑 3～5 条，说明为什么值得先看（一手材料、跨平台共识、与用户目标最相关）。这一节给判断，
但不给投资、医疗、法律类结论性建议。

由执行方写进 `selected.json` 的 `highlights` 字段：`[{"cluster_id": "E00x", "title": "标题", "why": "理由"}]`。
只写标题不写理由的条目会被跳过。

## 质检清单（渲染前逐条过）

- [ ] 条目数与口径章节数字一致
- [ ] 每条都有 URL
- [ ] 正文七个维度里前六个全部有值（时效形态可空）；附录条目可不打标
- [ ] 附录条数没超过配额，超出的列进了「未纳入条目与原因」
- [ ] 没有把热度分描述成浏览量
- [ ] 缺口如实写明，没有硬凑
- [ ] 每条正文都有摘要（excerpt 非空），且没有超过 200 字
- [ ] 摘要不与标题相同、比标题长、且不是套话——命中任一条都要回原网页重抓正文
- [ ] 前 5～10 条的摘要确实来自抓取的正文，不是搜索结果那一两句的改写
- [ ] 正文填了 `source_quality`；命中标题党的内容没有混进正文
- [ ] 「关键数据」表非空，且每行都有 `as_of`
- [ ] 「观点分布」每组都有论点和论据，开头写清了争议焦点
- [ ] 「核查情况」里「已证实 / 已辟谣 / 有争议 / 待核实」取值合法，没有用标签冒充核查
- [ ] 「本期要点」已填写，内容是依据各条摘要提炼的，不是标题复述
- [ ] 「值得优先关注的几条」每条都有理由
- [ ] 附录 A 里每条信源都能看到中文平台名与可点击的完整网址
- [ ] 限制章节完整
